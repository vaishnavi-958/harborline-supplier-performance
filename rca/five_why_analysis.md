# 5-Why

The chain is generated in `src/rca/five_why.py` from the worst scorecard row.

Method:

1. State the KPI problem (OTIF, defect, SLA) with the actual rates.
2. Split late vs short so Why-1 is not a generic “they were late”.
3. Move from demonstrated lead-time / fill-rate to planning method (ATP, freeze fence, P90 planning).
4. Stop at a process cause the buyer and supplier planner can act on.

Do not treat the fifth why as a legal finding. It is a workshop script for the independent project.
