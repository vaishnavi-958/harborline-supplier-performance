# Fishbone (Ishikawa)

Built for the **worst weighted-score supplier in the generated scorecard**, not a random name. Refresh after `python scripts/run_pipeline.py`. The Harborline Pareto page prints the live bones.

Typical bones for a late / short supplier:

- **Man** — promise dates without ATP; quality hold queue; ASN backlog
- **Machine** — bottleneck work center; test equipment; pack-line changeovers
- **Method** — no ATP gate; SLA on ship date not dock date; partials closed early
- **Material** — sub-component shortages; lot variation; undocumented substitution
- **Measurement** — promise vs request mix-up; header OTIF; in-transit damage in defect counts
- **Environment** — peak-season capacity; weather/port; receiving calendar not shared

This is a facilitated RCA template seeded by metrics, not an automated verdict.
