## 📌 Project Overview

Harborline is an independent **Supplier Performance & Procurement Analytics** project designed to demonstrate how procurement and supply-chain teams can transform purchase-order data into actionable supplier insights.

The platform evaluates suppliers across:

- On-Time In-Full (OTIF)
- Fill Rate
- SLA Compliance
- Lead-Time Variance
- Quality / Defect Performance
- Procurement Spend
- Unit-Price Variance
- Supplier Risk
- Supplier Scorecards
- Pareto Analysis
- Root Cause Analysis
- Procurement Follow-Up Actions

The project follows a complete analytical workflow:

```text
Purchase Orders
       ↓
Data Quality Validation
       ↓
Python + SQL KPI Pipeline
       ↓
Supplier Scorecard
       ↓
OTIF / Quality / Cost / Risk
       ↓
Pareto + Root Cause Analysis
       ↓
Procurement Action
